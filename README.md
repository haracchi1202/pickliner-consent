# ピックライナー イベント参加同意書システム（LIFF + GAS）

LINE公式アカウント「ピックライナー」のイベント参加者に、同意書を読んで同意してもらい、その記録をスプレッドシートに残す仕組みです。
サーバーやデータベースの契約は不要。**Google スプレッドシート + Google Apps Script（GAS）** だけで動きます。

- 参加者：LINEで同意書を開く → 名前を入力 → チェック → 送信 → LINEに受付番号が届く
- 運営：記録はスプレッドシート「同意記録」に自動で貯まる

## セットアップ手順（全体の所要時間：約1時間）

### 手順1：スプレッドシートとGASの準備（約15分）

1. Google ドライブで新しい**スプレッドシート**を1つ作成する（名前は何でもよい）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある `Code.gs` の中身を全部消し、このリポジトリの `Code.gs` の中身を貼り付けて保存する
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「**ウェブアプリ**」を選ぶ
5. 設定を以下にして「デプロイ」：
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**　←★ここを選び忘れると送信が全部エラーになります
6. 表示された**ウェブアプリのURL**（`https://script.google.com/.../exec` で終わる）を控える
7. 動作確認：そのURLをブラウザで開いて `consent endpoint ok` と出れば成功

### 手順2：LINE側の準備（約25分）

1. [LINE Developers](https://developers.line.biz/) にログインし、**プロバイダー**を1つ作成
2. そのプロバイダーに **Messaging API チャネル**を作成し、公式アカウント「ピックライナー」と紐づける
   - 「チャネルアクセストークン（長期）」を発行して控える（手順4で使います）
3. **同じプロバイダー**に **LINEログインチャネル**を作成　←★プロバイダーが違うとログインで失敗します
4. ログインチャネルの中で **LIFF** を1つ追加する
   - サイズ：**Full**
   - スコープ：**profile**
   - エンドポイントURL：仮でよい（手順3で正式なものに差し替え）
   - 発行された **LIFF ID** を控える

### 手順3：画面を公開してつなぐ（約15分）

1. `index.html` の先頭にある3つの値を埋める（下の「手で埋める値」参照）
   - `LIFF_ID`、`GAS_URL`
2. この `index.html` を **GitHub リポジトリの直下**に置き、**GitHub Pages** で公開する
   - 公開URL（`https://ユーザー名.github.io/リポジトリ名/`）を控える
3. 手順2で作った **LIFF のエンドポイントURL** を、この GitHub Pages のURLに設定し直す

### 手順4：トークン登録と設置（約5分）

1. GASの画面で「プロジェクトの設定」→「スクリプト プロパティ」を開く
2. プロパティ名 `CHANNEL_ACCESS_TOKEN`、値に手順2のチャネルアクセストークンを登録して保存
   - （登録しない場合でも記録は残りますが、LINEへの控え送信は行われません）
3. LIFFのURL（`https://liff.line.me/{LIFF_ID}`）を、公式アカウントの**あいさつメッセージ／応答メッセージ／リッチメニュー**のいずれかに設置して完了

## 手で埋める値の一覧

| ファイル | 場所 | 変数名 | 入れる値 |
|---|---|---|---|
| `index.html` | 先頭の設定ブロック（**11行目**） | `LIFF_ID` | 手順2-4で発行された LIFF ID |
| `index.html` | 先頭の設定ブロック（**13行目**） | `GAS_URL` | 手順1-6で控えた GAS ウェブアプリURL |
| `index.html` | 先頭の設定ブロック（**15行目**） | `CONSENT_VERSION` | 同意書バージョン（通常 `v1` のままでOK。文面を変えたら上げる） |
| GAS | スクリプトプロパティ | `CHANNEL_ACCESS_TOKEN` | 手順2-2で発行したチャネルアクセストークン |

## 同意書の文面を変えるには

`index.html` の中の

```
<!-- ===== 同意書本文（ここを差し替えてください） ===== -->
   …本文…
<!-- ===== 同意書本文ここまで ===== -->
```

このコメントで囲まれた部分だけを書き換えれば差し替えられます。
文面を大きく変えたときは `CONSENT_VERSION` の数字も上げてください（記録にどのバージョンに同意したかが残ります）。

## よくあるつまずき

- **送信が全部エラーになる** → GASのデプロイで「アクセスできるユーザー：全員」を選び忘れていないか確認
- **LINEログインで失敗する** → Messaging API チャネルと LINEログインチャネルが**同じプロバイダー**にあるか確認
- **画面が開かない** → LIFFのエンドポイントURLが `https` になっているか確認（GitHub Pages は https）
- **控えが届かない** → スクリプトプロパティ `CHANNEL_ACCESS_TOKEN` が正しく登録されているか確認（記録自体は残ります）

## やっていないこと（仕様）

- React / Next.js などのフレームワーク、ビルド工程、npm は使っていません
- 専用の管理画面はありません（記録の確認はスプレッドシートで行います）
- LINE の Webhook 受信は実装していません（控えの push 送信のみ）
